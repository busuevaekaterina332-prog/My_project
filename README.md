# Краткое содержание статьи  
## «Модель искусственного интеллекта для выявления заболеваний сердца с использованием алгоритмов машинного обучения»

> **Журнал:** Healthcare Analytics, Volume 2, 2022, Article 100016  
> **DOI:** [10.1016/j.health.2022.100016](https://doi.org/10.1016/j.health.2022.100016)  
> **Авторы:** Victor Chang, Vallabhanent Rupa Bhavani, Ariel Qianwen Xu, MA Hossain  

---

## Цель исследования

Разработка системы обнаружения заболеваний сердца на основе искусственного интеллекта с использованием:
- Языка программирования **Python**
- Алгоритмов **машинного обучения** для ранней диагностики
- Поддержки клинических решений через предиктивную аналитику

---

## Методология

- Язык программирования Python
```python
# Основные библиотеки
import pandas as pd      # работа с данными
import numpy as np       # численные вычисления
import matplotlib.pyplot as plt  # визуализация
import seaborn as sns    # статистические графики
from sklearn.ensemble import RandomForestClassifier  # ML-модели
from sklearn.model_selection import train_test_split # разделение данных
```
- **Датасет**: Данные UCI Machine Learning Repository (304 записи, 14 признаков: возраст, пол, уровень холестерина, артериальное давление, тип боли в груди и др.).
- **Предобработка данных**: работа с категориальными переменными, кодирование, масштабирование признаков, разделение на обучающую и тестовую выборки.
- **Алгоритмы для сравнения**:
  - K-Nearest Neighbors (KNN)
  - Decision Tree Classifier
  - Support Vector Machine (SVM)
  - Random Forest Classifier (основной выбранный метод)

---

## Результаты

- **Random Forest** показал высокую точность (83–84%) и устойчивость к переобучению благодаря усреднению прогнозов множества деревьев решений.
- Модель соответствует требованиям HIPAA по защите медицинских данных.
- Визуализация данных (тепловые карты корреляций, гистограммы) помогла выявить значимые признаки, такие как тип боли в груди и максимальная частота сердечных сокращений.

---

## Выводы
Исследование демонстрирует эффективность применения машинного обучения, в частности алгоритма Random Forest на платформе Python, для прогнозирования заболеваний сердца. Модель достигает высокой точности (83%) и может служить основой для разработки масштабируемых, динамичных систем мониторинга здоровья. Авторы рекомендуют внедрение аудита данных и обучение медицинского персонала работе с ИИ-инструментами для повышения качества диагностики.
